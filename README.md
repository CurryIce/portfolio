# My Portfolio

A bilingual portfolio of my work in level and gameplay design, from combat spaces and Blueprint gameplay to Unreal tools and personal prototypes.

**[View portfolio](https://curryice.github.io/portfolio/)** · **[English version](https://curryice.github.io/portfolio/en/)**

## Selected work

- **Marvel's Midnight Suns DLC:** encounter layouts, connecting spaces, and skill implementation.
- **FPS remaster:** level scripting and a tool for visualizing legacy level events.
- **Honor of Kings: World:** mission photo mode design and implementation.
- **Sokoban:** a playable prototype and an Unreal level editor.

Built with **Astro** and deployed on **GitHub Pages**. Chinese is the default language; an English version is available throughout the site.
